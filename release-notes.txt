- Improved & Fixed: Minor bugs, performance improvements, and UI enhancements for a smoother user experience.

- User Panel UI: Enhanced layout and responsiveness for a smoother user experience
- Backup System: New option to back up both files and database directly from the panel
- Timezone Support: Full universal timezone compatibility across system activities
- PayPal Gateway: Upgraded to the latest version for better integration and security
- PhonePe Gateway: Updated to the latest version for seamless transactions
- Invoice Format: Redesigned invoice template for better clarity and print-readiness
- Translation Manager: Add or update translation words directly from the admin panel

- Cron Job Settings: Configurable cron job settings via the admin panel
